## Architecture decision (supersedes product-count inference)
1. Stable public mission ID, versioned public brand; 200 individually verified experiences and final deliverables remain the target. Preserve original AE slug/flavor/bundle metadata, never use display names as keys.
2. Layer `mission catalog -> per-context policy/consent -> bounded domain workflow -> least-privilege tool gateway -> human-reviewed evidence/verified receipts -> native client`. Shared low-risk primitives are acceptable; 200 copies of a text formatter are **not**.
3. Gate every mission's real-world data access, sources, roles, approvals, retention, residency and rollback independently. No governmental accounts, public-law conclusions, personal records or real-world writes without scope-specific legal and technical clearance.
4. Native Android/iOS compilation, physical-device install, accessibility/RTL, security/privacy and outcome evidence are separate NO_GO gates. A successful Python queue is not an emulator or mobile build.
5. Track 200 decks (exactly 50-page 16:9 landscape English PDF) and 200 videos (exactly 60 s, English narration and burnt-in captions, genuine app capture, cleared Arabic instrumental score) separately. Final judging/submission requirements require official verification.
6. Destination is **public**. Do not migrate tokens, private resident/government records, commercially restricted assets, confidential research respondents, signatures or paid media. This initial source catalog received a basic credential-string scan, not a completed legal/IP or privacy audit; a qualified clearance is pending.
7. **Migration waves:** W0 identity/evidence preservation (this PR); W1 reusable contracts plus source/provenance-only native module import; W2 differentiated consented functionality and offline tests per category; W3 native build and device evidence, data safety and accessibility; W4 authentic presentation assets; W5 qualified final review. Do not promote a wave on file counts alone.
8. No merge, public deployment, submission, billable runner activation or user data transfer. New public branch and draft PR permit review without changing `main`.
